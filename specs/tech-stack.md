# Stack Tecnológica - Sitech

## 1. Visão Geral
Arquitetura moderna e unificada utilizando TypeScript de ponta a ponta, garantindo confiabilidade, tipagem estática e facilidade de manutenção.

## 2. Tecnologias Principais
- **Linguagem:** TypeScript
- **Framework Frontend & Backend:** Next.js (App Router / React)
- **Estilização:** Tailwind CSS (design responsivo e mobile-first)
- **Banco de Dados:** SQLite (armazenamento local leve e sem necessidade de infraestrutura externa)
- **ORM / Acesso a Dados:** Prisma ORM (modelagem tipada e migrações ágeis)
- **Autenticação:** NextAuth / Sessões protegidas para a área administrativa de notícias

## 3. Diretrizes de Arquitetura
- **Renderização Híbrida:** SSR/SSG para páginas públicas de cursos visando SEO e alta performance.
- **Área Administrativa:** Rotas protegidas para criação e gerenciamento de notícias.
- **Camada de Dados Mock:** Estrutura pronta para matrizes curriculares e cursos técnicos inspirados na base de referência.
- **Compatibilidade:** Otimizado para navegadores modernos e telas de smartphones/tablets.
